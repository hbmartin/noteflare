# PR #285 follow-up: local CPU benchmark

Measured 3 November 2026 against the working-tree application sources recorded in commit `568d874`, based on main `d1a2024`. Subsequent static cleanup `820a3c3` only removed unused exports. The benchmark script is unchanged. All resources were ephemeral local Miniflare resources; no preview/production resources or credentials were used. Other local validation overlapped, so wall timings are not a controlled before/after comparison.

These are whole-process CPU upper bounds, not Cloudflare invocation CPU. They cannot separate HTTP caller CPU from hashing DO CPU or establish Free-plan compatibility. The separate heartbeat regression demonstrates one coverage request and zero row pages for unchanged 2,000-row windows; this benchmark does not measure that browser request schedule.

## Recorded benchmark output

These process totals cannot separate HTTP caller CPU from PasswordCrypto DO CPU. Idle I/O is excluded. CPU profiling is off by default to avoid sampler overhead. Optional raw V8 profile durations are diagnostic only: local workerd can attribute unsampled idle gaps to active frames. Separate computeElapsedMs measures wall time for production transformations, including async DOCX and password hashing RPC. Per-step production Workflow code uses an instrumented step.do shim; engine persistence/retry overhead excluded. Local hardware measurements, not Cloudflare metering or enforcement.
